✨ Planned highlights

Based on the xterms (terminal-app) product specs and README:

  • SSH Connections — Manage hosts, ports, and users with a powerful connection manager.
  • Host Groups — Organize your servers with nested groups (up to 3 levels), custom colors, and icons.
  • SFTP Browser — Full file management: upload, download, rename, move, delete, and manage permissions.
  • Remote File Editor — Edit text files directly on your server with syntax highlighting and a 5MB limit.
  • Terminal Experience — VT-style session output with custom fonts, sizes, and themes (Default, Dracula, Monokai, Solarized).
  • Port Forwarding — Support for Local, Remote, and Dynamic (SOCKS) port forwarding rules.
  • Quick Commands — Boost productivity with pre-configured command shortcuts.
  • Security-minded UX — Biometric lock, auto-lock timeout, and encrypted password storage.
