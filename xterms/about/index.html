xterms is an iOS SSH terminal app (Flutter). It focuses on dependable connections, sensible authentication options, and a clean terminal UI. This site section is published ahead of the App Store release so you can prepare Support URL and related links.

🚀 Vision

To provide developers and system administrators with a robust, secure, and mobile-friendly environment for managing remote servers. xterms combines the power of a desktop terminal with the convenience of a mobile app.

🛠 Key Features

  • Advanced SSH & SFTP: Seamlessly switch between terminal sessions and file management.
  • Customizable Environment: Choose from popular terminal themes and adjust typography to your liking.
  • Efficient Organization: Keep your connections tidy with nested host groups.
  • Productivity Boosters: Use quick commands and port forwarding to streamline your workflow.
  • Security First: Protect your access with biometric authentication and encrypted storage.

📱 Platforms

  • iOS / iPadOS: Optimized for touch input and external keyboards.
  • Coming soon: Stay tuned for updates on other platforms.
