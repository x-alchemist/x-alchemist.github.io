Report a bug for xterms

If you encounter issues with xterms, please help us improve by reporting them.

📥 How to report

Send an email to jason.xiang@outlook.com with the following details:

  1. Device & OS version (e.g., iPhone 15, iOS 17.4)
  2. App version (if known)
  3. Steps to reproduce the issue
  4. Expected vs. actual behavior
  5. Screenshots or screen recordings (if applicable)

🛠 Feature requests

We also welcome suggestions for new features! Let us know how we can make xterms better for your workflow.

Note: As the app is currently in pre-launch, we appreciate your patience as we work through early feedback.
